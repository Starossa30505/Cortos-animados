# Cortos-animados
Skill para Claude Code que dirige y produce cortos animados hechos 100 % en código, sin generadores de video con IA. Ofrece 99 estilos de película (lemo-opuscar) y cortos verticales de historia con personajes 2D en un mundo 3D (Remotion + three.js), con guion, voz, música, render y control de calidad.
